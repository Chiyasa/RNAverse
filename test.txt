download the model weights and benchmark datasets
We have uploaded the model weights and benchmark datasets of RNAverse to Zenodo for direct download. Users are required to download them
from the link below and place them in the respect folder and unzipped afterwards:
Model weights of RNAverse, RNAverse-aptamer, RNAverse-UTR, RNAverse-SHAPE can be downloaded from Zenodo: https://zenodo.org/records/20527121/,
and should be placed into the ./model_weights/ directory
Benchmark datasets used in RNAvere can be downloaded from Zenodo: https://zenodo.org/records/20526662 and should be placed into the 
./data/ directory

Alternatively, we provide the command lines for users to download the model weights and benchmark datasets:

git clone https://github.com/Chiyasa/RNAverse.git

# download RNAverse, RNAverse-aptamer, RNAverse-UTR, and RNAverse-SHAPE
# under the ./model_weights/ directory
wget https://zenodo.org/records/20527121/files/rnaverse.zip
unzip rnaverse.zip

wget https://zenodo.org/records/20527121/files/rnaverse_aptamer.zip

wget https://zenodo.org/records/20527121/files/rnaverse_utr.zip
unzip rnaverse_utr.zip

wget https://zenodo.org/records/20527121/files/rnaverse_shape.zip
unzip rnaverse_shape.zip

# download benchmark datasets

Zero-shot in-painting
RNAverse can directly design RNA functinal classes that exist in the multimodal alignment stage use the zero-shot in-painting strategy. Here we take RNAverse-gACA19 as an example:
python ./generation/in_painting.py \
    --init_seq ./data/design/RNAverse_gACA19_init.fa \
    --model_name_or_path ./model_weights/rnaverse \
    --rfam_id RF00413 \
    --random_seed "42 \
    --seq_num 5000 \
    --max_token_per_iter 5 \
    --output_fa /path/to/output/RNAverse_gACA19.fa


Fine-tuned in-painting
For the RNA fucntional clasees absent from the alignment corpus, RNAverse can be fine-tuned with the MLM objective using the sequences of the target RNA classes.
Here we take the IGFBP3 aptamer SELEX sequences as the example.
Notice: the func_vocab.json and rfam_map.json should be edited first to include the novel functional class, like those under the ./model_weights/rnaverse-aptamer

python3 ./examples/ft_mlm.py \
    --batch_size 32 \
    --lr 5e-6 \
    --pad_len 1025 \
    --random_seed 37 \
    --model_path ./model_weights/rnaverse \
    --config_path ./model_weights/rnaverse-aptamer \
    --tokenizer_path ./model_weights/rnaverse-aptamer \
    --save_model_dir /path/to/output/ \
    --max_epoch 200 \
    --tol_epoch 8 \
    --whether_ft 1 \
    --train_txt ./data/design/datasetA_IGFBP3_P6_train_rnaverse.txt \
    --test_txt ./data/design/datasetA_IGFBP3_P6_test_rnaverse.txt

we provide the trained model weights of RNAverse-aptamer, which can be directly used for the in-painting generation of IGFBP3 aptamer
python ./generation/in_painting.py \
    --init_seq ./data/design/RNAverse_aptamer_init.fa \
    --model_name_or_path ./model_weights/rnaverse-aptamer \
    --rfam_id IGFBP3_aptamer \
    --random_seed "42 \
    --seq_num 5000 \
    --max_token_per_iter 1 \
    --output_fa /path/to/output/RNAverse_aptamer.fa


Iterative optimization
We provide the model weights of RNAverse-UTR and RNAverse-SHAPE, which can be directly used for the iterative optimization to design 5' UTR
python3 ./generation/iterative_optimization.py \
    --out_dir /path/to/output/ \
    --cds ATGGTGAGCAAGGGCGAGGAGCTGTTCACCGGGGTGGTGCCCATCCTGGT \
    --design_length 150 \
    --nbr_sequences 500 \
    --evolved_iter 500 \
    --nbr_bases_to_mutate 6 \
    --rnaverse_shape_model_path ./model_weights/rnaverse-shape \
    --rnaverse_utr_model_file ./model_weights/rnaverse-utr/best_model.pt \
    --bs 32 \
    --random_seed 42
